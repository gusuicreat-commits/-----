# 台词规则

## 占位与出处

- 参数用 `{{F_rated_load}}`，类比用 `{{A_girder_length_football_field}}`；大小写和 ID 必须一致。
- 每镜头 fact_refs 收录台词、数据卡、焊缝及类比依赖的参数；analogy_refs 收录台词与 params.analogy 的所有类比；asset_refs 收录实拍素材。
- 数字只用可引用参数或程序类比。不能将 brief 里的数字直接转成事实，必须与 facts 对照。
- 展开：m→米、mm→毫米、t→吨、个→个、m/min→每分钟数值米；整数不带小数点，其他单位保留原标识。
- 阿拉伯数字全部检查；中文数字计量如「三十米」「百吨」「两层」也会拦截。
- 「第一」「之一」「一起」「一直」「一定」「统一」「唯一」「万一」等惯用语可保留；「一根头发丝」等泛指量词不等于设备数值。
- 不把数字改写为中文以躲避校验；「波音747」含数字，应放在程序生成的 A 占位符中。
- 台词占位符必须保留在最终 narration；narration_resolved 是供审读的派生字段。

## 类比与重复

A 占位展开的是完整短语；直接写「主梁长{{F_girder_length}}，{{A_girder_length_football_field}}。」。
不要写「相当于{{A_x}}」「大约{{A_x}}那么高」，因为类比本身可能已有相同词。
程序检查相邻重复的 2–6 字短语与冗余修饰，比如「主梁主梁」「相当于相当于」「那么宽粗细」。
「稳稳」「慢慢」等自然叠词允许；脚本并不理解所有语义重复，展开后仍需通读。

## 时长

规划时：`duration_s >= len(narration_resolved) / 4.5 + 0.8`。
字数采用字符数，含标点、单位、数字，与后端 len 一致；这是估算而非真实配音时长。
后端 NARRATION_TOO_LONG 的触发式为 `len(text)/4.5 > duration_s + 1`，比规划留量宽松；移植脚本保持此阈值。
全片必须 30–60 秒；用户指定 30 秒投标时按 30 秒设计，不能仅凭落在总范围内就说达标。

## 素材与语气

reference 素材使用「像这样的造船门机」「这类装备」；禁止「这台」「本机」「我们的」。
own 素材可以在事实支撑下用设备指代，但不得据画面猜出未确认参数。
reference 素材保留「参考实拍 · 非本机」标签和 credit；不得用本机参数冒充参考画面的实测数值。
科普亲切、短句、一镜头讲清一个重点；展会强调可见结构；投标克制陈述参数和出处。
不要无证据宣称「世界第一」「零误差」「绝对安全」，也不要把结构示意说成装配实拍。
人工改过的台词，只改命中问题的词句；保留其他句子、语气与镜头 id。
