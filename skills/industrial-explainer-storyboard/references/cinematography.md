# 工业装备多角度导演指导

当用户要求片子更长、更多角度或转场时读取。目标是让新增时间提供新的空间信息，而不是重复环绕、拉慢同一段视频。时长、镜数和风格服从本次需求；30–45 秒可容纳尺度、局部关系和类比，但不是所有项目的强制时长。

## 先给每镜一个任务

起草导演表时注明：时段、观众此刻应看懂什么、景别与机位、观察对象、相机起终状态、事实/模型依据、与前后镜如何衔接。纯视觉建立镜可以少台词，避免每次换角度重复同一数字。新增镜头若不能回答新的问题、建立方位或完成有意的情绪收束，就删除或合并。

全景建立整机边界与位置，中景展示部件之间的空间关系，近景突出已有几何细节；切回全景让观众重新定位。可采用“近景设问 → 全景揭示 → 中近景观察 → 全景比较 → 收束”的节奏，不要求三种景别机械轮换。近景不是必须出现焊缝：没有精度事实和对应资产就不安排 weld_macro。

## 轴线、运动与尺度

- 开拍前从实际模型确定世界轴、主梁长轴、设备正面和镜头所在侧；在导演表中约定屏幕上的长度方向。连续观察同一部件时保持方向连贯；跨轴前用可见的绕行、正面中性镜或全景重新建立方位，避免切镜后设备突然“掉头”。
- 相机绕行不等于设备运动。未确认 rig 时可以观察静止几何，不让轮组、吊钩或小车动起来；真实运动还须有轴、行程、速度与必要倍速标识。
- 机位变化不能改变几何比例。所有镜头沿用同一模型、坐标和单位；不为“更震撼”单独拉长主梁、放大轮组或压扁参照物。模型缺的细节不由 AI 生成后冒认真实设备。
- 广角低机位可以表达体量，但不能凭透视画面读出精确比例。数值类比镜使用同尺度、同投影与明确对齐基线，比较同一维度；长度不拿跨度或起升高度代替。比例和比较词仍由 compute_analogy 计算，字幕留出处与“示意”边界。
- 俯视、侧后方、局部拆解说明的是可见几何和部件位置。节点存在、颜色高亮或爆炸图均不是受力路径、强度、稳定性、承载能力或传动原理的证明；这些讲解需要另行确认的工程资料。

## 过渡由信息关系决定

| 相邻镜头关系 | 可选过渡 | 检查重点 |
|---|---|---|
| 问题到整机揭示、部件到全貌 | 直接切镜；必要时按形状/方向匹配切 | 观众能否认出同一部件，主体位置是否突跳 |
| 同一观察方向继续移动 | 顺运动切镜或连续相机路径 | 屏幕运动方向、速度和起终位置是否相容 |
| 侧面转到背面或俯视 | 可见绕行，或插入建立方位的全景 | 是否跨轴、是否失去正反面关系 |
| 观察整机转到尺度对照 | 直接切至稳定比较构图；有必要时短叠化 | 不在叠化重影期间读比例；投影和标尺先稳定 |
| 信息讲完到片尾 | 停稳留读、轻淡出或直接收尾 | 字幕读完、旁白收住，末帧不截断主体 |

不要为“更多转场”给每镜加入不同特效。遮挡转场、甩镜、缩放和长叠化只有在引导目光且不遮住几何与数字时才采用。转场覆盖在既定时间线内，写清重叠时长，不把过渡无意叠加成额外片长；重要数值在稳定画面期间完整可读。

## 先关键帧，再整片

先让渲染负责人输出各镜的起、中、末关键帧，以及切点前后或转场中间帧，连同对应台词和标注供验收。检查主体是否完整、近景是否辨得出所属部件、机位是否穿模/遮挡、轴线与运动方向是否连续、比较比例与文字是否清楚。构图不成立先改机位，不靠整片渲染掩盖问题。

关键帧通过后才进入整片；仍须看片检查运动速度、节奏、转场、文字停留和声音衔接。静帧通过不等于成片通过。此技能只提出验收任务与返工方向，不声称已自动评判审美；事实规则校验也不会检查投影、模型真实性或渲染画面。

## 本轮可选例：36 秒、八镜

以下仅为 T26 本次独立加长版导演计划，不是应用 profile、选择器输出或已渲染的证明。应用 T25 的 scale_film 仍为三镜、15–30 秒。

| 时段 | 镜头 | 信息功能与衔接 |
|---|---|---|
| 0–4s | detail，近景 | 用真实模型已有主梁局部建立问题；按主梁方向切到全貌 |
| 4–9s | hero，全景 | 交代整机轮廓与主梁尺度；稳定建立正面与屏幕方向 |
| 9–13s | side/back orbit，中全景 | 展示此前被遮住的纵深与后侧；绕行可见，不突然跳到轴线另一侧 |
| 13–18s | leg/wheel，中近景 | 看清支腿和轮组的相对位置；静止观察，不推出承载或行走性能 |
| 18–22s | girder traverse，中近景 | 沿主梁观察延展，使用相机横移，不冒称小车工作运动 |
| 22–27s | elevated，全景 | 从高位重建部件空间关系；不将俯视轮廓当受力分析 |
| 27–32s | compare，稳定全景 | 同尺度比较主梁与参照物；程序计算比例，留足读数时间 |
| 32–36s | closing hero，全景 | 回到整机完成收束，保留来源与示意标注，不再追加新参数 |

此表给导演/渲染负责人实施。现有 shotlist 只使用 schema 已支持的 kind 与 params；不支持的横移路径、景别、过渡和关键帧约定放在单独导演说明，用 shot id 对齐，不塞入虚构执行字段。若用户要求应用一键生成本方案，应单独实施并验证渲染能力，不能改写三镜配置后沿用旧片验收。
