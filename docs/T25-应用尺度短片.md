# T25 应用尺度短片模式

新增 `render_mode=scale_film`：使用已确认事实直接编译 detail/hero/compare 三镜模板，不调用 LLM 生成分镜。标准模式与原 photoreal 路径保持原分支；没有将旧 T24 样片作为渲染输入或缓存。

## 使用与输入边界

原子设置示例：

```json
{"render_mode":"scale_film","director_recipe":"scale","target_s":15}
```

目标仅 15–30 秒，director_recipe 为 scale/auto，仅参数化模型。缺省设置仍沿用原项目规则；跨字段不合法返回 422，原设置不写入。STEP 明确拒绝。本模式需要有出处且 confirmed/verified、无冲突的主梁总长和整机高度；尺寸支持 m/mm，原 facts.json 保持原值/单位/出处，渲染事实另存 `model/scale-film-facts.json` 并带 original_id/value/unit。高度、跨度、起升高度不能代替主梁总长；规范 ID 与名称/key 冲突、语义同指主梁但数值不同的别名均停止。

auto 在临时生成模型的实际节点上调用共享选择器，必须实际选中 scale 且 analogy axis=length。运动主题缺 rig、明确高度主题等不适用请求会停止，不自动换题。明确 scale 是用户指定长度模板。临时模型只有通过选择后才替换正式 GLB，失败清理临时文件。

跨度/总长、起升高度/整机高度不相容时拒绝；底层参数化几何的容纳约束仍生效。默认跨度、主梁高等来自既有 `_dimensions`，记录 model.assumed；附属结构为示意。默认值不会写成确认事实。

## 单一来源与分镜保护

`skills/industrial-explainer-storyboard/references/director-recipes.json` 下 `scale.render_profiles.scale_film` 是三镜角色、权重和占位台词的唯一来源：4/5/6（15 秒），其他目标按比例分配。原 scale 默认 3/7/5 未变。

`agent/scale_film.py` 编译 shotlist、claims、程序 compute 类比；tool 事件为 `director.scale_film`。每次从 plan 启动都按归一化参数重建 GLB 与 rig，避免修改总长后沿用旧模型。整条流水线从头运行时，即使已有旧 shotlist 也会进入此模板规划。

approved/human_edited 镜头只在固定三角色内、创作字段和当前输入完全兼容时逐字段保留，包含原 id、时长、review 及自定义字段；否则停止，不丢弃。PATCH narration/params 自动记 human_edited=true，pending 不代表可以覆盖。后续任意创作字段改变都会使模板状态失效，必须明确处理后重跑。

## 渲染、音频与最终产物

仍先运行标准 validator；scale_film 自身不走 photoreal 数量门槛，也未降低 photoreal 规则。阻断不能强制越过；渲染前再次校验。执行专用脚本：

```text
Blender --background --factory-startup --python-exit-code 1 --python blender/scale_film.py -- --config /abs/config.json --out /abs/cache
```

config 包含 version=1、1920×1080、30fps、绝对 normalized facts_file、三个 id/role/start/end。输出契约：noaudio.mp4、projection.json、manifest.json。projection 为第三镜 field/girder 归一化矩形、length_m、reference_length_m=105、reference_width_m=68；执行器检查范围、长度、同基准投影比例及视频时长。

media 执行器复用 `media.blender._render` 的超时/进度；缓存 hash 纳入当前输入、来源、分镜时间线、全部 Blender Python 脚本及尺寸规则。完成记录保存产物 SHA-256，缓存文件损坏会重跑。缺 Blender、脚本失败、缺产物、投影不符或时长不符都停止，不静默回退网页/旧风格。

- `renders/video_noaudio.mp4`：专用 Blender 无声画面。
- `renders/final.mp4`：当前片动态 ASS 标题/出处/类比、实际配音与原创合成声景；不复用 T24 成片。
- `renders/scale-film-render.json`：当前渲染缓存与投影记录。

配音使用既有 tts（Edge/系统回退按原实现）；本模式保存实际 engine/duration/words/spoken_text。超镜头预算直接停止，不截音、不静默延长；时间线也拒绝旧配音文本不匹配。未新增 Edge 总超时。ASS 根据实际 fact、source.doc/page、程序 analogy.text 和 projection 生成，示例标识根据实际事实/来源文本判定；始终标注参数化示意、非真实测绘。声景为程序原创合成，不声称实机录音。

QA 从最终 MP4 逐镜抽帧，不取旧网页播放器。视觉 provider 不可用记录 warn 和“未完成”，不冒充通过。报告 JSON/HTML 记录模式、确定性模板、实际事实与出处、模型 assumed、实际 TTS 引擎/metadata、声景说明。
