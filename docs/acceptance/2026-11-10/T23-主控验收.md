## 独立验证

- Node 基础/光照/运动/相机参数检查：31通过，见 `T23-aster-unit.txt`。
- 几何及投影检查：18通过，输出 `web/test-results/T23-aster-geometry`。
- 真实 Chrome / Apple M4 硬件 look：10通过、1跳过，见 `T23-aster-look.txt`。跳过的是重复整片导出；实施者已在同一冻结运行时完成一次整片导出，主控另行检查其媒体信息。
- 整片导出进程总耗时139.814秒；该数值来自实施者的 `after/render-result.json`，不是主控重跑耗时。
- 固定双面诊断视角：受光/背光有效样本4968/8324，gamma比2.00677、linear比3.56605，地面阴影/亮面比0.43886。3∶1继续仅为诊断，不作为成片硬门槛；诊断视角不能代表所有成片机位。
- 媒体、色彩和光照原始结果见 `T23-aster-metrics.json`。
- 首次布局子集8通过4失败；已发现旧双列、旧五标签解析和透明容器边界等断言与新排版不一致。扩大到58项播放器回归后51通过7失败，日志 `T23-aster-player-final.txt` 保留原结果。七项按实际内容边界、真实HUD位置和背景采样区域修正后，主控独立复跑 **7通过（7.8秒）**，见 `T23-aster-seven-final.txt`。因此58项在同一冻结运行时下分批通过；不是伪称首次整套全通过。后续只改测试，视频与运行时未变，不重复全片渲染。

七项修正保留：实际数字卡与尺寸标签互不遮挡、短引线锚定/净空/具体HUD避让、按selector正确区分上下HUD、设备核心及类比参照物完整入画、两侧4%背景采样避开主体、背景硬边检查，以及回退/乱序恢复一致性。地面延伸轨道不充当天空中的设备遮挡；俯视类比左上是地面，蓝天由独立硬件look的实际天空机位检查。

可复现命令（项目 `web` 目录）：

```sh
KEPU_FULL_PLAYER_REVIEW=1 KEPU_CHROMIUM_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npx playwright test -c tests/t23-review.config.mjs
```

该配置保留为可复用验收入口；默认运行12项重点布局，启用环境变量运行58项。排除的短片导出测试已由本轮完整1500帧导出覆盖。最终 `git diff --check` 通过。

主控发现的真实兼容性回归（环绕镜头忽略显式角度/距离）已在视频导出前修复；两个非默认参数组合验证 `distance × diagonal`、方位、俯仰和乱序一致性。独立美术分镜只调整镜头参数，未将其冒充与旧片完全相同的摄影机输入。
