# T26 多角度加长版：制作与验收

日期：2026-11-11。最终视频与本地观看页已完成；Astra 最终抽帧验收通过，可交付查看。

## 本轮目标与变化

用户要求延长视频、增加不同角度与转场，提升观看效果，并核对 Skill 制作进度。本轮制作独立 **36 秒、8 镜、1080p、30fps** 导演版。此前 T25 成片为15秒、3镜；本轮增加侧后方、轮组、梁顶、高位俯瞰与另一侧收束机位，使用真实三维相机运动，不将旧片拉慢或重复拼接。

| 时间 | 镜头 | 新增观看信息 |
|---|---|---|
| 0–4s | 主梁下方近景 | 从局部建立尺度问题 |
| 4–9s | 低机位全景 | 整机轮廓和104m示例主梁 |
| 9–13s | 侧后方绕行 | 被正面遮挡的一侧 |
| 13–18s | 支腿／轮组近景 | 轮组、支腿与轨道相对位置 |
| 18–22s | 沿主梁横移 | 走台和小车的可见几何 |
| 22–27s | 高位俯瞰 | 整机空间布局 |
| 27–32s | 正交尺度比较 | 104m主梁和105m参照同尺度显示 |
| 32–36s | 另一侧全机拉远 | 回到整体，收束观看路径 |

前五处过渡直接切镜，配合原创合成声景；27s和32s各8帧短叠化，扩展前镜末帧后在原时间轴内重叠，保持总长36s。比较读数从27.45s开始，31.9s前退场，不在重影期间阅读比例，不把比较标尺叠到透视整机上。

## 配音、脚本与事实边界

八句旁白由 Edge TTS `zh-CN-YunjianNeural` 实际生成，逐段探测音长并检查不越出镜头；未截断或加速塞入。背景音为原创程序合成，非商业音乐、现场录音或设备运行音。

本轮真实执行独立 Skill 的 `compute_analogy.py → resolve_text.py → validate_shotlist.py`，八镜脚本结果0 block、0 warn、1 info（待人工复核），无 input_errors、skipped 或 delivery_warnings。主梁数字使用事实占位符，比例由程序计算。镜头路径另放导演时间线，不扩展不存在的执行字段。标准 shotlist 的 `model_orbit` 只是交换描述，实际相机轨迹以本轮独立脚本为准。

[八镜分镜](../outputs/T26-multiangle/editorial/shotlist.json)、[校验报告](../outputs/T26-multiangle/editorial/validation-report.json)、[实际旁白及音长](../outputs/T26-multiangle/audio/voice.json)。

104m、51m来自项目示例技术参数表，不代表真实厂家、设备或现场核验。模型为程序化结构示意，未新增制造商 CAD；局部近景不证明真实装配、受力或承载性能。球场按105×68m绘制，只作为选定参照；不同球场尺寸并非全部一致。配音中的比较词沿用程序词库结果。

## Skill 实际进度

独立分镜、参数溯源、类比计算、真实性校验以及尺度／运动／结构配方已有可用实现。本轮加入多角度摄影参考：镜头信息功能、景别、轴线、比例、转场选择和关键帧验收。Skill本身仍负责分镜与校验，不执行渲染、配音、合成。

应用一键 `scale_film` 仍为三镜、15–30秒；本轮36秒八镜是独立导演成片，不声称应用已接入。完整真实模型有／无Skill对照评测、自动审美返工、运动／结构同等级成片仍待做。详情见 [Skill进度审计](T26-Skill进度.md)。本轮未提交或部署。

## 复现入口

项目根目录：

```sh
backend/.venv/bin/python outputs/T26-multiangle/prepare_editorial.py
backend/.venv/bin/python outputs/T26-multiangle/make_voice.py
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python outputs/T26-multiangle/render/render_film.py -- --stills --audit
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python outputs/T26-multiangle/render/render_film.py -- --film
python3 outputs/T26-multiangle/finish_film.py --audio --previews
python3 outputs/T26-multiangle/finish_film.py --compose
python3 outputs/T26-multiangle/verify_film.py
node outputs/T26-multiangle/check_viewer.mjs
```

正式制作应在关键帧审查后才执行 `--film`；每镜支持续渲。`make_voice.py` 会访问 Edge TTS；其余后期处理使用本地工具。渲染元数据和日志保存在 `outputs/T26-multiangle/render/`，最终媒体检查保存在 `acceptance/`。
