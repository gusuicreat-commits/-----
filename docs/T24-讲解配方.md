# T24 讲解配方与应用入口

三份配方已接入同一选择器；启用后 planner 实际读取技能内的 JSON，不是另写一套后端 prompt。默认未启用、45 秒、无人工锁定镜头时，现有 system/context 与录制回放保持不变。新增能力的证据为离线行为测试和独立复制运行；尚不能据此声称真实模型创作质量或成片审美已通过。

## 单一来源与选择

- `skills/industrial-explainer-storyboard/references/director-recipes.json`：scale / motion / structure，每份有观众问题、所需事实/rig/模型节点、带参数的镜头顺序、禁用条件、观察标准及失败返工对应关系。
- `skills/industrial-explainer-storyboard/scripts/select_director.py`：标准库独立入口。只返回选中的紧凑配方，不把三篇长文拼进每次请求。auto 先按需求关键词确定主题，命中主题缺证据则 needs_evidence，不换成另一个有证据的主题；没有明确主题关键词时才根据可用证据选一份。显式选某配方同样不暗换题。
- `backend/app/agent/director.py`：加载同一技能选择器，避免复制规则。`planner._context` 在启用时加 `director`；缺证据在 LLM 调用前终止，并列所缺输入。

只有 confirmed/verified、出处 doc/page/quote 完整且无冲突的事实可作为选择依据。尺度仅接受语义明确的正数主梁总长(girder_length)或整机高度(overall_height)，支持 m/mm，与 girder 节点；ID/key/name 冲突以及跨度、起升高度、臂长和其他部件尺寸均拒绝，因为现有 analogy 几何量的是主梁长度或整机高度；运动需要实际节点、有效 rig 行程和该轴 speed_fact 对应的确认 m/min 速度；结构需要模型节点以及明确说明主梁/支腿组成的 qualitative 文字事实。模型节点不证明受力、传动、连接方式或工程性能。

配方提供参数建议，不承担原文真实性、模型几何或 rig 现场标定验收。类比比例继续由既有 compute 工具计算；数字占位、claims、实拍来源、真实性校验不放宽。

## 用户可用的设置

`PATCH /api/projects/{pid}/settings` 支持任意字段的局部更新：

```json
{"director_recipe":"scale","target_s":15}
```

`director_recipe` 为 `off|auto|scale|motion|structure`，缺省 off；`target_s` 为 10–120 秒，缺省 45。原 `render_mode` 的独立 patch 保持兼容。设置不隐式重跑；后续从 plan 重新生成。显式传给 Python plan 的 target_s 优先于项目设置。

15 秒采用 3–4 镜头预算，配方各自默认 3 镜；尺度分配为 3/7/5 秒，运动 3/8/4，结构 4/7/4。只讲一个问题，不强塞 45 秒的所有主题、实拍、焊缝与多参数卡。planner 对短片或已启用配方的生成结果检查镜头数和总时长（误差 ≤1 秒）；不满足就停止而非保存错误预算。台词仍需按展开字数和实际语音检查。

photoreal 既有 validator 的 exploded/motion 硬性要求仍在，不因 15 秒尺度配方自动放宽；发生冲突应交人工决定，不擅自改模式或降级告警。

## 人工编辑保护

全片重规划遇到 approved/human_edited 时，先预留原镜头时长，把原 id 和剩余预算交给模型；合并时逐字段使用原镜头，包含自定义字段。模型遗漏锁定 id、重复 id、人工镜头占满目标预算、合并后超预算均停止，旧 shotlist 不被覆盖。自动 repair 跳过锁定镜头并发出保留事件；问题仍留给后续校验和人工处理。用户明确点名 revise 某镜头属于授权改写，该镜头重新回到 pending。

## 对原评测的影响与未完成验证

默认 off 的既有应用录制保持原行为；显式配方、短片前缀、带人工锁定的全片重规划会产生新的 prompt 哈希，原 45 秒 cassette 不能拿来证明这些新请求的模型行为。Skill 的 15 秒和配方优先规则会改变新一轮真实模型产物；过去的 with_skill/without_skill A/B、触发率、可溯源率与盲评结果不能自动沿用。没有重跑完整真实模型 A/B 或触发评测，也没有修改其评分/哈希逻辑掩盖变化。

`observe_and_rework` 是给人工查看成片时使用的具体观察/返工指导，当前没有自动审美评判、自动审美返工或质量提升量化证据。新的真实模型 forward 与样片需由主控独立验收；仍须检查静音可读性、同基准比例、遮挡、参数来源、真实台词时长和最终导出。

主控复核后补充：尺度选择器按现有播放器几何收窄语义，auto 对已命中的缺证据主题不再降级换题。新增仅跨度、起升高度、臂长、部件长度、ID/key/name 语义冲突与规范 ID/key/name 的 m/mm 换算行为用例。播放器几何和默认 cassette 未改。
