# T24 尺度样片

本样片只讲主梁长度：近景揭示 → 全机低机位 → 严格正交尺度比较。画面是本项目示例技术参数驱动的程序化示意，未使用制造商CAD、实物测绘、AI生成设备或真实厂区素材。主梁104m、全机51m、跨度88m来自已有示例文件；不能据此声称某实际设备的参数已核验。

## 独立实现和复用范围

- 新增 `blender/t24_scale_film.py`，只读取公共 `common.py` / `crane.py` / `scene.py`，不修改原有运行时或播放器。
- 复用 `build_crane()` 的箱梁、外露肋板、倒角、爬梯、小车卷筒绳槽、轮组和绳索几何。现有附属结构仍是工程示意，不是实物构造证明。
- 增加米制中性CG舞台、细颗粒地面、橙红涂装微法线、冷暖大面积补光及薄雾。背景不代表任何真实厂区。
- 第三镜只显现原主梁节点，将其整体平移到比较平面；未变形、未改变长度。与105×68m标准化球场同一正交镜头，长度比104/105，非真实场地。
- 0–4s近主梁机位横移并转向；4–9s相机约5.5–6m高，缓慢推近；9–15s锁定正交相机，便于主控合成信息。相机由绝对时间求值，不积累状态。

## 制作命令

在项目根目录执行（Blender 5.2.3；本机沙箱内Metal可能退出139，因此已授权项目渲染使用沙箱外执行）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python blender/t24_scale_film.py -- --mode stills
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python blender/t24_scale_film.py -- --mode film --width 1920 --height 1080
```

静帧为1280×720；全片为1920×1080、30fps、450时间线帧、15秒。实际独立渲染271帧：0–269为前9秒真实相机运动，270为静止正交首帧，271–449硬链接保持，不重复计算渲染。脚本支持 `--start` / `--end` 精确续渲。干净画面输出 `outputs/T24-scale-film/frames/%05d.png`；字幕/数字/source按 `overlay-config.json` 由主控合成，干净帧本身不含来源字样，不能直接当公开完成片发布。

## 审图和边界

审图优先看实图，不以3:1或旧机械像素标准代替美术判断。首轮补光/雾过强，随后调整；主控拒绝俯视、大面积粗糙地面的桌面模型感，定向改为低机位、细地面和中性空气层。三张关键帧交主控审查后再渲整片。

材质提升仅限程序噪声和光照，没有实测漆膜、贴图扫描、焊缝或制造公差级建模。现有支腿顶架高出梁面的构造、司机室/吊钩简化仍可见。不能称为实拍级、真实装配验证或制造商交付片。

实际耗时和相机记录由 `stills-*-manifest.json`、`film-*-manifest.json`及日志记录；不得用估计冒充全片实际耗时。声音和最终合成由主控完成。完成整片后脚本使用ffmpeg将450时间线帧拼为无声 `noaudio.mp4`，不烧录文字，不能代替带来源的最终发布片。
